# Roadmap

Done means built, tested and running in the private build. Nothing below is published in this repo yet.

## Done (private build)

- [x] Terminal prototype of the office (August 2026)
- [x] Live window version wired to Claude Code hooks (September 2026)
- [x] Floor plan, walk grid and pathfinding that keeps people off walls and out of each other's space
- [x] 13 characters, 5 pets, shared and personal animations
- [x] Tool calls routed to the worker who owns that kind of work
- [x] Conference room huddle for big prompts and parallel subagents
- [x] Scripted idle conversations that act themselves out (walk to the cooler together, start a pool game)
- [x] On and off switch so the office only opens when wanted
- [x] 383 automated checks

## Next

- [ ] Strip personal content (real names, likenesses, private art) and ship a default cast
- [ ] Custom workers: a config file for name, look, outfit and specialty
- [ ] Sprite builder or import path for your own characters
- [ ] One worker per real subagent, so each subagent Claude spawns gets its own desk and laptop
- [ ] Planning meeting that shows the actual plan in speech bubbles
- [ ] Worker to worker text bubbles that reflect real hand-offs between subagents
- [ ] "Answer in" banner at the top of the screen
- [ ] Bring the Claude tab back to the front when the answer is ready
- [ ] One-command install for Windows, macOS and Linux
- [ ] Pick a license and publish the code

## Later

- [ ] Office themes and layouts
- [ ] Support for other coding agents that expose hooks
- [ ] Recordable replays of a job, start to finish
